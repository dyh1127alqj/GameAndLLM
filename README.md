# GameAndLLM

> **项目定位**：本项目为**「尝试使用大语言模型（LLM）作为工程研发辅助工具与智能 Agent」**来独立开发的一款现代化卡牌自走棋肉鸽游戏。  
> **游戏本体定位**：**100% 纯单机、离线、确定性**游戏，游戏运行时完全不依赖、不包含任何大模型网络调用，保障零延迟、零网络开销与种子绝对可复现。  
> **官方指定引擎**：**Godot Engine 4.x (.NET / C# 12)**。

---

## 一、核心玩法与题材

- **题材背景**：**多元宇宙无限流**。轮回者穿梭于不同风格反差强烈的世界（首发世界：【蜀山断裂仙界】×【赛博霓虹蜂巢】），掠夺位面法则，合成概念级跨界超武。
- **战斗模式**：**纯全自动自走棋 (Auto-battler)**。战前布阵、插槽装配与路线规划决定胜负。
- **战斗策略支柱**：
  1. **素体与权能 (Vessels)**：取消固定职业，素体具备先天四阶权能与专属本命大招（怒气驱动）；
  2. **插槽羁绊 (Affixes & Synergies)**：核心槽决定职业，6 大职业羁绊（守卫/强袭/秘术/巡林/暗影/支援）按插槽件数分 (2)/(4)/(6) 档触发；
  3. **战前战术指令 (Gambit System)**：每位素体可配置 2 条战前战术指令（条件 + 动作），解决全自动战斗下 AI 愚蠢集火与空放技能的痛点；
  4. **跨界超武融合 (Super Weapons)**：集齐满级不同世界血脉词条，可在特定节点合成质变超武（如【纳米飞剑】、【超维黑客剑阵】）。

## 二、架构设计与技术栈

项目采用**物理级解耦的双核驱动架构**：

```
┌─────────────────────────────────────────────────────────────┐
│                    Godot 4.x 表现与交互层                    │
│   (2D 场景 / Spine 与 Sprite 动画 / CanvasItem 着色器 / UI)    │
└──────────────────────────────┬──────────────────────────────┘
                               │ 订阅事件流 (DamageEvent 等) / 传入战前快照
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 纯 C# 确定性领域核心类库 (.NET 8)               │
│  ┌─────────────────────────┐     ┌───────────────────────┐  │
│  │   GameCore.Battle       │     │   GameCore.Rogue      │  │
│  │   - 确定性无头战斗内核    │     │   - 三轨肉鸽状态机    │  │
│  │   - 四阶修正器/拦截器管线│     │   - 词条插槽与羁绊引擎│  │
│  │   - 战术指令 (Gambit) 判定│    │   - 种子确定性事件系统│  │
│  └─────────────────────────┘     └───────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- **纯 C# 领域逻辑层**：`GameCore` 类库，零外部引擎依赖，可在命令行中秒级运行 10,000 场无头蒙特卡洛战斗模拟以极速平抑数值；
- **Godot 表现层**：`GodotClient` 工程，专职作为事件消费者，处理动画、打击感、飘字缓冲与战前拖拽交互。
