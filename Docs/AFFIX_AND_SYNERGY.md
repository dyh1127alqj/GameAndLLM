## 一、插槽拓扑与词条分类

### 1.1 插槽矩阵定义
每位出战素体依据其权能等级（Level 1~4）与成长状态（基础阶 / 进阶阶），最多解锁 4 个插槽：

| 插槽类型 | 英文标识 | 默认解锁阶段 | 允许镶嵌的词条种类 |
|---|---|:---:|---|
| **核心槽 (Core Slot)** | `Slot_Core` | 开局解锁 | **职业词条 (Class Affix)** 专属槽位，决定该素体的战术职能定位 |
| **作战槽 (Combat Slot)** | `Slot_Combat` | 进阶解锁 | **技能词条 / 触发型战技**，提供由法力驱动的局内主动战技 |
| **通用槽 (Utility Slot)** | `Slot_Utility` | 开局解锁 | **世界血脉 / 属性增幅 / 机制改造**，提供数值底盘与世界套装标签 |
| **奇点槽 (Singularity)** | `Slot_Singularity` | 进阶+Lv3/4 | **超武融合物 / 概念级特性**，专属顶级词条槽 |

> **开局保底规则 (D-08b)**：玩家初始大名单中的每个素体，进局时默认在【核心槽】预装 1 枚对应职能的 Lv1 基础职业词条，绝无"裸奔无职"的真空期。

### 1.2 词条强类型数据模型
```json
{
  "affix_id": "affix_cyber_nano_blade_01",
  "name": "高频纳米振动刃",
  "slot_type": "Combat",
  "quality": "Rare",
  "tags": ["Cyber", "Striker"],
  "stats": {
    "AtkFlat": 45,
    "AtkMult": 0.05
  },
  "passive_behavior": {
    "trigger": "OnNormalAttackHit",
    "effect": "ApplyBleed",
    "params": { "dot_rate": 0.08, "duration": 3.0 }
  },
  "fusion_target": "affix_super_concept_cutting"
}
```

## 二、六大基础职业羁绊规格

羁绊按全队上阵素体装备的该职业词条**总件数**计算档位。  
**生效范围规则 (D-08a)**：
- **(2) 件档位**：仅对佩戴该职业词条的单位生效；
- **(4) 件档位**：仅对佩戴该职业词条的单位生效，效果质变；
- **(6) 件档位**：**全队所有 5 名出战单位无差别全额生效**。

| 职业羁绊 | 标签名 | (2) 档位效果 (装备者生效) | (4) 档位效果 (装备者生效) | (6) 档位终极效果 (全队生效) |
|---|---|---|---|---|
| **守卫 (Guardian)** | `Guardian` | 护甲提升 25%，每秒获得相当于自身最大生命 2% 的护盾（上限 20%）。 | 护甲提升 60%，每秒自然回复 5 点法力 (`ManaRegenPerSec = 5`)。 | **坚壁共鸣**：全队常驻获得 40% 减伤，全场友军受到致命伤害时保留 1 点生命并获得 2 秒无敌（每场限 1 次）。 |
| **强袭 (Striker)** | `Striker` | 物理伤害提升 20%，行动条充能速度 (`Charge`) 提升 15%。 | 攻击附带 30% 护甲穿透，普攻命中时额外获得 10 点法力与 5 点怒气。 | **绝对压制**：全队攻击力总乘区 ×1.5，所有攻击无视目标 50% 护甲，击杀目标立即回满自身行动条。 |
| **秘术 (Mystic)** | `Mystic` | 战技与大招伤害提升 25%，最大法力上限需求降低 15 点（85 满蓝释放）。 | 技能伤害附带目标 5% 最大生命的法术穿透，施法后返还 30 点法力。 | **法术洪流**：全队受到的技能伤害减少 30%；全队释放技能时触发连锁闪电，对随机 3 名敌方造成 50% 溅射伤害。 |
| **巡林 (Ranger)** | `Ranger` | 射程 +1（近战变半远程，后排可越过前排直击敌方前排），对距离大于 2 格的目标伤害提升 25%。 | 普攻有 35% 概率触发连击（立即追加一次 70% 伤害的普通攻击）。 | **箭雨风暴**：全队攻击速度 (`Speed`) 提升 40%；友方后排单位的所有攻击自动索敌敌方血量最低的目标。 |
| **暗影 (Shadow)** | `Shadow` | 战斗开局进入隐匿状态 3 秒（无法被选为单一目标），首次攻击造成 200% 伤害。 | 每次击杀使自身重新进入隐匿 2 秒，背刺（攻击敌方后排）伤害提升 50%。 | **寂灭终焉**：全队造成伤害的 15% 转化为自身生命吸取；敌方单位生命低于 20% 时受到任意伤害直接被斩杀。 |
| **支援 (Support)** | `Support` | 治疗量输出 (`HealingDone`) 提升 30%，行动条充能不会因受击而退火减半。 | 友方单位受到治疗时，清除其身上的 1 个可驱散控制/减益状态。 | **生命源泉**：全队免疫所有退火与打断机制；全队受到致死伤害时由支援者均摊 50% 伤害，且全队常驻每秒回血 3%。 |

## 三、首发两大世界血脉套装

首发两大世界（D-03）：**蜀山断裂仙界 (Shushan)** 与 **赛博霓虹蜂巢 (Cyber)**。

### 3.1 蜀山仙剑血脉 (`Shushan`)
- **(2) 剑意初成**：装备者释放技能或大招后，在身侧凝聚 1 枚灵气飞剑。飞剑在下一次普攻时协同射出，造成等同于自身攻击力 80% 的物理剑气穿刺伤害。
- **(4) 万剑归宗**：飞剑上限提升至 5 枚。当集齐 5 枚飞剑时，自动融合成一柄【巨阙虚影】轰击敌方密集区域，造成 400% 范围真实伤害并眩晕目标 1.5 秒（计入控制递减）。

### 3.2 赛博蜂巢血脉 (`Cyber`)
- **(2) 纳米覆甲**：战斗开局获得相当于自身 35% 最大生命的纳米能量屏障。屏障存在期间，免疫灼烧与流血等 DOT 伤害。
- **(4) 矩阵过载**：当生命值首次跌破 50% 时，进入持续 6 秒的【算力过载】状态：攻击速度与充能速度提升 100%，所受伤害延后 4 秒结算，且期间普通攻击附带高频电弧跃迁。

## 五、词条背包与装卸流通规则

### 5.1 背包容量与溢出结算 (D-16)
- **备用背包容量**：固定 **10 格**；
- **溢出处置**：当战斗掉落或事件获取新词条且背包已满（10/10）时，界面弹出【就地取舍】弹窗：
  1. 丢弃多余词条；
  2. 将选定词条就地【精炼】，分解转化为相当于其品质等级的信用点（普通 15 / 稀有 35 / 史诗 80 信用点）。

### 5.2 拔插装卸时机 (D-14)
- **安全节点（营地 Rest、行商 Shop）**：允许玩家无限制、无代价地在素体插槽与备用背包之间自由装卸、拔插、调换词条；
- **行军途中（常规战斗、精英战、位面异象途中）**：所有素体插槽**强制锁定**，禁止临时调换配装，玩家必须依靠战前规划的构筑迎战。

### 5.3 重伤流通规则 (D-09a)
- 素体阵亡进入【重伤】状态后，仅该素体无法出战；
- **其插槽上的词条绝不锁定**。玩家可以在安全节点将重伤素体身上的词条卸下，重新装配给其他替补健康素体，避免构筑资产因偶发战损而连带瘫痪。

## 六、数值防爆与软钳制规范 (D-13)

为杜绝无限流肉鸽在后期产生"数值破表导致战斗死机或秒杀 Boss"的崩塌，战斗计算层引入严格的**软钳制（Soft Cap）管线**：

```csharp
public static class BalanceCaps
{
    public const float MaxDamageReduction = 0.75f;     // 总减伤率硬上限 75%
    public const float MaxChargeRate = 3.0f;            // 行动条充能速度倍率上限 300%
    public const float MaxAttackMultiplier = 5.0f;      // 攻击总乘区上限 x5.0
    public const float MinHealingReceived = 0.20f;      // 重伤致死率下限 20%
    public const float MaxHealingReceived = 3.00f;      // 治疗放大上限 300%
    public const float MaxDotPercentHpPerSec = 0.15f;   // 全 DOT 合计每秒扣血上限 15% MaxHp
}
```

任何乘区超过基础阈值后，超出部分按双曲函数衰减：
$$\text{EffectiveMultiplier} = \text{Cap} \times \left(1 - \frac{1}{1 + \frac{\text{RawMultiplier}}{\text{Cap}}}\right)$$
保证构筑永远有提升，但永远不会击穿战斗时钟底线。
