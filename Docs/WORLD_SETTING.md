## 一、设定骨架

### 1.1 一句话定位 🎨

> 你是**主神空间**的一名调度者。你没有自己的身体，只有一批被从各个崩坏世界打捞回来的**素体**。
> 你把它们派进一个又一个濒临崩溃的位面，用从那些世界里剥下来的**词条**改造它们——
> 然后看着它们打，看着它们死，再决定下一个进去的是谁。

### 1.2 结构骨架（由已决机制反推，非创作）

设定必须承载以下五件已决的机制，缺一不可：

| 机制（已决） | 设定上必须提供的承载物 |
|---|---|
| 玩家**不参与**战斗（D-04 全自动） | 玩家不是战场上的人，而是**远程调度者**——这解释了为何无法微操 |
| 素体**无先天职业**，职业可装卸（D-08） | 素体是**空白容器/躯壳**，职业是外来的"权限模块" |
| 词条来自**不同世界**且可跨界融合 | 世界之间原本不相通，**主神空间是唯一枢纽** |
| 单局失败后**下一局重新开始**，但有长线积累 | **轮回**——失败不是终点，记忆与传承会留下 |
| 单局 = 1 个世界（✅ D-22） | 每次"任务"投放到一个指定位面，3 层 × 6 步 |
| 阵亡 → 重伤 → 花信用点救治（✅ D-09） | 素体**不会真死**，只会损坏待修——为反复轮回提供叙事合理性 |

### 1.3 三个层级

```
┌─────────────────────────────────────────────┐
│ 主神空间 (Meta Hub)  ——  局外，永久          │
│   世界星图 / 素体大名单 / 传承保险库 / 科技树  │
└───────────────────┬─────────────────────────┘
                    │ 投放
┌───────────────────▼─────────────────────────┐
│ 位面任务 (World Run)  ——  单局，3 层         │
│   路线推进 / 素体招募 / 插槽装配 / 羁绊构筑    │
└───────────────────┬─────────────────────────┘
                    │ 遭遇
┌───────────────────▼─────────────────────────┐
│ 自动战斗 (Battle)  ——  单场，20~40 秒        │
│   零输入，纯观战                              │
└─────────────────────────────────────────────┘
```

### 1.4 关键设定问题 🎨

以下三个问题会显著影响文案基调，建议早定：

| 问题 | 选项 |
|---|---|
| **主神是什么** | 冷酷的系统 / 有人格的存在 / 身份成谜（可作为长线悬念） |
| **素体有没有自我意识** | 有（则阵亡有情感重量）/ 无（则可无负担消耗）/ 越强越有 |
| **玩家为何被困在这里** | 惩罚 / 交易 / 不明（无限流经典） |

> 推荐：**主神身份成谜 + 素体权能越高自我越强 + 玩家被困原因不明**。三者都留白，给后续内容更新留出空间，同时"高星素体开始反抗"是一个天然的叙事钩子。

## 四、元素环与各世界表皮

✅ 依据 [D-02](DESIGN_DECISIONS.md)。

### 4.1 内核枚举（唯一真值）

```csharp
public enum Element { None, Metal, Wood, Water, Fire, Earth }
```

**克制环**：

```
Fire → Metal → Wood → Earth → Water → Fire
（火克金，金克木，木克土，土克水，水克火）
```

| 关系 | 系数 |
|---|:---:|
| 攻击方克制受击方 | `1.25` |
| 受击方克制攻击方 | `0.75` |
| 无克制 / 任一方 `None` | `1.00` |

### 4.2 各世界显示表皮 🎨

| 内核枚举 | W-01 末日生化 | W-02 赛博蜂巢 | W-03 蜀山仙界 | W-04 旧日深渊 |
|:---:|---|---|---|---|
| `Metal` | 合金 | 纳米 | 金 | 星骸 |
| `Wood` | 菌毒 | 生体 | 木 | 孢生 |
| `Water` | 酸蚀 | 数据 | 水 | 潮汐 |
| `Fire` | 辐射 | 过热 | 火 | 燔祭 |
| `Earth` | 尘障 | 磁场 | 土 | 岩渊 |

### 4.3 ⚠ 实现铁律

> **映射表只作用于 UI 显示与特效选择，不得进入任何逻辑判断。**
> 克制关系判定永远走内核枚举 `Element`。
> 违反此条会导致同一套数值在不同世界产生不同结果，破坏配平与确定性。

## 5.3 ⚠ 这是职能重构，不只是改名

定案的六职业是一套**标准六职业原型**（坦 / 物DPS / 法DPS / 远程 / 刺客 / 奶），优点是定位零重叠、玩家秒懂、战术指令易于适配。代价是 v1.0 的**三条标志性机制不再是职业身份**：

| v1.0 机制 | 原属 | 现状 |
|---|:---:|---|
| 残血增伤 `1 + 0.6×(1-HpRatio)` | 近系 | ⛔ 不再是职业天赋 |
| 30% 概率再动 | 速系 | ⛔ 不再是职业天赋 |
| 普攻 25% 概率流血 | 弓系 | ⛔ 不再是职业天赋 |

**三条机制均已作为技能词条回归**，见 [AFFIX_AND_SYNERGY 2.2](AFFIX_AND_SYNERGY.md)。

设计意图：**定位清晰度由职业承担，记忆点由词条承担**。词条是可刷取、可组合的，把记忆点放在词条上比放在职业上更适合肉鸽——玩家每局都在重新发现它们，而不是开局就固定拥有。

## 六、世界目录

### 6.1 首发范围 ✅ [D-03](DESIGN_DECISIONS.md)

**已定案**：首发 **2 个世界 —— W-03 蜀山断裂仙界 + W-02 赛博霓虹蜂巢**，素体规模收敛至 20~24 个。

## 八、剧情与叙事文案口径约束

无论由人工撰写，还是借助 LLM 辅助工具离线生成静态剧情与异象事件文案，均须遵守以下**文案层面的硬约束**：

### 8.1 核心约束守则

1. **术语绝对一致**：所有剧情与 UI 文本必须严格使用第二、三、五节的标准术语，绝对禁用第七节的废弃词；
2. **不得自创机制**：叙事文本中不得出现战斗内核不存在的机制（如暴击、格挡、闪避、连击等未决/不支持词汇）；
3. **不得承诺数值**：叙事文案中不得出现具体数值承诺（如"使攻击力翻倍"），数值一律由配置表和结构化字段驱动。
